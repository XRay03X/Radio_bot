# 📻 Universal Radio Bot

Egy minimalista, stabil és nagy teljesítményű Discord zenebot, amelyet online rádióstreamek (MP3, AAC, HLS) 24/7 közvetítésére terveztek.

---

## 🚀 Főbb jellemzők
- **Széleskörű formátumtámogatás:** Kezeli az `.mp3`, `.m3u8`, `.pls` és közvetlen IP-alapú streameket.
- **Automatikus Újracsatlakozás:** Ha a stream megszakad, a bot megpróbál újra kapcsolódni.
- **FFmpeg Optimalizáció:** Alacsony CPU használat és pufferelés elleni védelem.
- **Egyedi Stream Listák:** Könnyen bővíthető rádióállomás-gyűjtemény.
